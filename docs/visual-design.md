# Profile motion

Original animations are generated with Pillow by running `python scripts/generate_motion.py` from the repository root. The generator uses DejaVu Sans Mono fonts from `/usr/share/fonts/truetype/dejavu`.

The header and localized terminal GIFs loop every 10.8 seconds. They are committed directly so rendering does not require a hosted animation API or a scheduled GitHub Action. The original project artwork remains unchanged. The terminal is an illustrative introduction, not live command output or a deployment status indicator.

References consulted:

- [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg): typing effects and timing controls.
- [Platane/snk](https://github.com/Platane/snk): GIF/SVG motion in GitHub profile READMEs.
- [DenverCoder1 profile template](https://github.com/durgeshsamariya/awesome-github-profile-readme-templates/blob/master/templates/DenverCoder1.md): banner, animation and section hierarchy.
- [Abhishek Naidu profile template](https://github.com/durgeshsamariya/awesome-github-profile-readme-templates/blob/master/templates/abhisheknaiidu.md): animated developer imagery alongside profile content.

These references informed the motion direction; no third-party animation assets were copied.
