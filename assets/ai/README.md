# AI stack badges

Local SVG badges using icons from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under CC0. The full license is in `LICENSE.simple-icons.txt`.

- Gemini: `googlegemini`
- LangChain: `langchain`
- LangGraph: `langgraph`
- CrewAI: `crewai`
- pgvector: the PostgreSQL icon identifies the database extension; this is not a separate official pgvector logo.

Embeddings, RAG, hybrid search, tool calling and memory are techniques rather than brands, so they are presented as text. Frameworks without a locally available verified icon keep their names rather than an invented logo.
